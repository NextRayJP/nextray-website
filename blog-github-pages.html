サーバー代0円でホームページを運営する仕組み｜GitHub Pagesという選択肢

ホームページの維持費は、何にかかっているのか

ホームページの維持費というと、ひとまとまりの「管理費」として請求されることが多いのですが、中身を分解すると、だいたい次の要素でできています。

  • サーバー代——ページのデータを24時間置いておく場所の賃料
  • ドメイン代——「〇〇.jp」などの住所の年間使用料
  • SSL証明書——通信を暗号化する仕組み（鍵マークの正体）
  • 保守・更新の人件費——中身を直したり、安全に保ったりする作業

このうち、いちばん「払っている実感がないのに毎月かかる」のがサーバー代です。この記事はその部分を0円にできる場合がある、という話です。維持費全体の考え方は費用相場の記事にも書いています。

GitHub Pagesとは何か

GitHub（ギットハブ）は、世界中のソフトウェア開発者がプログラムのコードを保管・公開するために使っている、業界では標準的なサービスです。運営はMicrosoftの傘下企業で、公開されているコードの多くがここに置かれています。

そのGitHubには、「保管しているファイルを、そのままウェブサイトとして公開する」という機能があります。これがGitHub Pagesです。HTMLファイルを置けば、それがそのままインターネット上のページになります。

  • 公開機能は無料——サーバーの賃料に相当する費用がかからない
  • 独自ドメインを使える——当社のnextray.jpもこの機能で接続している（ドメイン代・年数千円程度は別途かかる）
  • SSLも無料で自動——鍵マーク（https）の証明書が自動で発行・更新される
  • 更新の反映が仕組み化されている——手元でファイルを直して送信（push）すると、本番サイトに反映される

なぜ無料なのか

「無料」と聞くと、何か裏があるのではと考えるのが健全です。ここは正直に整理しておきます。

GitHubの本業は、企業や開発者向けの有料プランです。Pagesは、開発者にサービスを使い続けてもらうための付帯機能という位置づけで、いわば本業のついでに提供されています。広告が勝手に入ることもありません。

ただし、無条件・無制限ではありません。

  • 容量と転送量に上限がある——サイトの容量や月間の転送量に目安の上限が定められている。通常の会社案内サイトで届く量ではありませんが、上限は存在します
  • 利用規約がある——商取引そのものを主目的とするサイト（通販の決済など）の運用は認められていない。会社案内・情報発信のサイトは問題ありません
  • 仕様は変わりうる——外部サービスである以上、条件が将来変わる可能性は常にあります

当社はこれらを理解したうえで、「静的な情報発信サイトなら、規約にも上限にも余裕をもって収まる」と判断して使っています。

静的HTMLだから成立する

ここが仕組みの核心です。GitHub Pagesで公開できるのは静的なサイト——あらかじめ完成したHTMLファイルを、そのまま配るだけのサイト——に限られます。

WordPressのようなCMSは、訪問者がページを開くたびに、サーバー側でプログラムがデータベースから記事を取り出してページを組み立てます。この「サーバー側で調理する」工程があるため、調理場つきのサーバー（＝有料のレンタルサーバー）が必要になります。

一方、当社はWordPressを使わず、HTMLとCSSを直接書いて制作しています。ページはすべて完成品として置いてあるので、配るだけの無料の仕組みで足ります。つまり「サーバー代0円」は単独の技ではなく、作り方の選択とセットです。静的に作るからこそ成立します。

副産物もあります。調理の工程がないぶん表示が速く、プログラムの脆弱性を突かれる攻撃面も小さくなります。WordPressの管理画面の乗っ取りやプラグインの脆弱性といった、CMS特有の心配事が構造的に存在しません。

当社の実際の使い方

当社は、この自社サイト（nextray.jp）と、制作物の一部をGitHub Pagesで公開しています。運用の流れはこうです。

  • 手元のパソコンでHTMLファイルを編集する
  • 変更内容を記録して、GitHubへ送信（push）する
  • 数十秒〜数分で、本番のサイトに反映される

変更の履歴がすべて記録として残るのも利点です。「いつ、どのページの、どこを直したか」が後から全部たどれるので、間違えて消しても過去の状態に戻せます。バックアップを別に取る運用より確実です。

お客様のサイトの月額29,800円には、サーバー・ドメイン・SSLの費用と管理を含めています。土台の費用を抑えられる仕組みを選んでいることは、この料金を維持できている理由のひとつです。

正直に書く弱点

良いことばかり書いても信用に関わるので、弱点をまとめて書きます。

1. お問い合わせフォームが、単体では作れない

フォームの送信内容を受け取って処理するには、サーバー側で動くプログラムが必要です。静的サイトにはそれがありません。実際にはフォーム部分だけ外部のフォームサービスを組み合わせるのが定石で、当社サイトのお問い合わせフォームもその方式です。予約システムや会員機能など、動的な機能はすべて同様に外部サービスとの組み合わせになります。

2. 専門知識が要る

公開までにはgit（ギット）という変更管理の道具の操作、HTMLの知識、ドメインの接続設定が必要です。WordPressのような管理画面はなく、ブラウザだけで記事を書いて公開する、という使い方は基本的にできません。「無料らしいから自分で」と始めて、公開前に挫折してしまうと本末転倒です。

3. 何かあったときのサポート窓口がない

無料の機能なので、電話で相談できる窓口はありません。トラブル時は自力（または依頼先）での解決になります。

4. 外部サービスへの依存になる

GitHubの仕様変更や障害の影響を受けます。これは有料レンタルサーバーでも同じ構図ですが、「無料の機能は仕様変更の告知が淡白になりがち」という一般論は頭に入れておくべきです。当社はファイル一式が常に手元とGitHubの両方にあるため、万一のときは別のサーバーへ載せ替えられる状態を保っています。静的HTMLはこの引っ越しが簡単なことも利点です。

向くサイト・向かないサイト

まとめると、次のような線引きになります。

  • 向いている——会社案内、店舗紹介、メニューや施工実績の掲載、ブログ・コラムなど、「情報を見せる」ことが主目的のサイト。中小企業のホームページの大半はこちらです
  • 向いていない——通販の決済そのもの、会員制サイト、在庫と連動する予約システムなど、サーバー側の処理が本体のサイト。規約の面でも技術の面でも、専用のサービスを使うべきです

なお「向いていない」側も、全部をあきらめる話ではありません。たとえば通販は、決済をShopifyやSTORESなどの専門サービスに任せ、会社案内や商品紹介の部分を静的サイトで持って接続する、という分担ができます。当社の制作でも、外部通販サービスとの接続はこの考え方で対応しています。

よくあるご質問

GitHub Pagesは本当に無料ですか？なぜ無料なのですか？

公開機能自体は無料です。GitHubは開発者向けの有料サービスで収益を上げており、Pagesはその開発者を集めるための付帯機能という位置づけです。ただし独自ドメインの取得費用（年数千円程度）は別途かかりますし、利用規約と容量・転送量の上限があります。無条件・無制限の無料ではありません。

GitHub Pagesでお問い合わせフォームは作れますか？

GitHub Pages単体では作れません。フォームの送信内容を受け取って処理するプログラムをサーバー側で動かせないためです。実際には、フォーム部分だけ外部のフォームサービスを利用して組み合わせるのが一般的で、当社サイトのお問い合わせフォームもその方式です。

通販サイトもGitHub Pagesで作れますか？

推奨しません。技術的な制約に加えて、GitHubの利用規約上、商取引そのものを主目的とするサイトの運用は認められていません。通販は通販専用のサービス（ShopifyやSTORESなど）を使い、会社案内やメニュー紹介などの情報発信部分を静的サイトで持つ、という分担が現実的です。

WordPressのサイトをGitHub Pagesに移せますか？

そのままでは移せません。WordPressはサーバー側でプログラムとデータベースを動かす仕組みで、GitHub Pagesにはその実行環境がないためです。移すには、サイトを静的なHTMLとして作り直す作業が必要になります。ページ数や機能によって手間が大きく変わるので、個別の検討が必要です。

まとめ

整理します。

  • GitHub Pages——完成したHTMLをそのまま公開できる仕組み。サーバー代に相当する費用が0円
  • 成立条件は静的HTML——サーバー側で組み立てる工程がない作り方（脱WordPress）とセットの技
  • 独自ドメインもSSLも使える——当社のnextray.jp自体がこの仕組みで動いている実例
  • 弱点は動的機能と専門知識——フォームは外部サービスの組み合わせ。管理画面はなく、gitの操作が要る
  • 向き不向きがはっきりしている——情報を見せるサイトには向く。決済や会員機能が本体のサイトには向かない

この仕組みを紹介したのは、「自分でやってみてください」と言うためだけではありません（できる方はぜひ挑戦してください。費用はかかりません）。それ以上に、維持費の内訳は分解して考えられるということをお伝えしたかったからです。毎月の管理費のうち、土台の実費はいくらで、作業の対価はいくらなのか。それが説明できる契約かどうかは、依頼先を選ぶうえでのひとつの目安になると思います。当社の料金の内訳は、すべて料金ページで公開しています。

現在のサイトのURLと、差し支えなければ維持費の内訳をお知らせいただければ、何にいくらかかっている構成なのかを整理してお伝えします。当社にご依頼いただかなくても、費用は一切かかりません。「今の契約のままで問題ない」と判断した場合は、正直にそうお伝えします。無理な営業や、しつこい追客は行いません。
